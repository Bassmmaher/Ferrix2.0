# Ferrix

Ferrix is a cross-platform application built with **Flutter and Dart**, designed to provide a consistent and responsive experience across multiple platforms.

The project supports:

- Android
- iOS
- Web
- Windows
- macOS
- Linux

## Overview

Ferrix is built using Flutter's cross-platform development framework, allowing a single codebase to target multiple operating systems while maintaining a consistent user interface and application architecture.

The project is organized with a focus on maintainability, platform support, and future development.

## Features

- Cross-platform Flutter application
- Responsive user interface
- Shared Dart codebase across supported platforms
- Native platform support for Android, iOS, Windows, macOS, and Linux
- Web support
- Modular project structure
- Easy development and deployment with Flutter

## Getting Started

### Requirements

Before running Ferrix, make sure you have:

- [Flutter](https://flutter.dev/)
- Dart SDK (included with Flutter)
- Android Studio or another supported IDE for Android development
- Xcode for iOS/macOS development on macOS
